# 🎨 Personal Portfolio Website

A responsive personal portfolio website built to highlight my skills, projects, and professional journey.

## ✨ Features

- **Responsive Design** - Works seamlessly across all devices (mobile, tablet, desktop)
- **Modern UI/UX** - Clean and professional interface
- **Project Showcase** - Display your best projects and work samples
- **Skills Section** - Highlight your technical and professional skills
- **Contact Form** - Easy way for visitors to get in touch
- **Smooth Animations** - Interactive elements for better user experience
- **Performance Optimized** - Fast loading and smooth interactions

## 🛠️ Tech Stack

- **HTML** (36.5%) - Semantic markup for content structure
- **CSS** (46.3%) - Styling and responsive layout
- **JavaScript** (17.2%) - Interactive features and animations

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/DODANGHOANCNTT2K15/Personal-portfolio-website.git
   cd Personal-portfolio-website
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser, or
   - Use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

3. **View your portfolio**
   - Open `http://localhost:8000` in your browser

## 📝 Customization

### Update Personal Information
Edit `index.html` to add:
- Your name and title
- Bio and introduction
- Contact information
- Social media links

### Modify Styling
Edit `styles/style.css` to customize:
- Color scheme
- Fonts and typography
- Layout and spacing
- Responsive breakpoints

### Add Interactivity
Edit `scripts/script.js` to add:
- Smooth scrolling
- Form validation
- Animations
- Dynamic content loading

## 📱 Responsive Breakpoints

- **Mobile** - up to 480px
- **Tablet** - 481px to 768px
- **Desktop** - 769px and above
